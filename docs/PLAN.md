# FrameOS Studio 开发计划

| 阶段 | 本地验收条件 |
| --- | --- |
| 一 · 环境与原型 | 启动首页和编辑器。用浏览器检查桌面和窄屏。 |
| 二 · 数据与基本编辑 | 可编辑场景、镜头、时间轴与真实素材。刷新后恢复。 |
| 三 · 分镜与时间轴 | 验证标注、图层、缩放、时间轴和项目导出。 |
| 四 · 真实媒体 | 扩充格式验收和大文件处理。 |
| 五 · 导出与打磨 | 完善成片渲染和导出细节。 |
| 六 · 质量与登记准备 | 完成验收、技术文档、操作截图和本地提交。 |

## 第一阶段方案

- 用 React、TypeScript 和 Vite 搭建本地网页。
- 用 Hash 路由保留刷新后的页面位置。
- 用 Dexie 管理本地项目和编辑数据。
- 用 Radix Dialog 实现键盘可操作的弹窗。
- 用 Motion 连接路由、面板和列表动画。
- 用 Konva 绘制监看画面和构图线。
- 用 Lucide 统一界面图标。
- 自定义 CSS 负责布局和设计变量。

项目根目录为 `D:\Projects\FrameOS`。
npm 缓存、临时目录和浏览器均放在项目内。
调研与验证证据见同目录的审查和测试文档。
