# V2 M0/M1 Audit

Audit date: 2026-11-24. Baseline: `870c343f773e7d227dc4659eabf49b61f7867511`, branch `feat/shotweft-v2-ai-director`. Package stays `1.5.0`. This document distinguishes the starting implementation from the additive M1 work in this working tree. It is not acceptance of M2–M6 or a distribution decision.

M1 supports three authored graphic scene types, captions, static camera, safe local audio, and explicit cut/shared-element transitions. `slow-push`, presenter media and visual footage are data contracts reserved for later work and fail explicitly at compilation. Chart bars are a deterministic illustrative scene, not an external-data chart engine. Plan files carry their own media paths and do not claim portability through V1 project ZIPs.

Verification and exact limitations are recorded in [TEST_REPORT.md](TEST_REPORT.md). Upstream provenance and terms are in [V2_UPSTREAM_RESEARCH.md](V2_UPSTREAM_RESEARCH.md). No upstream example media is copied into product assets.
