# 第二阶段功能说明

## 场景与镜头

- 在「剧本」里添加场景或编辑场景属性。
- 拖动场景把手可排序。方向键也可排序。
- 删除场景会解除镜头关联。撤销可恢复关联。
- 在「镜头」里搜索、筛选、复制和删除镜头。
- 在「镜头」和「时间轴」里拖动把手排序。
- 镜头排序同时更新列表和时间轴。
- 镜头属性面板同步更新画布和预演时长。

## 素材与分镜

- 在「素材」里上传图片或视频。
- JPG、PNG 和 WebP 图片上限为 25 MB。
- MP4 和 WebM 视频上限为 120 MB。
- 实际可播编码取决于浏览器。
- 点开素材预览，再选择「用于当前镜头」。
- 调整裁切缩放，并拖动画布移动裁切位置。
- 方向键也可微调画布裁切。
- 裁切参数和原图分开保存。
- 播放视频或拖动进度，再点「提取关键帧」。
- 视频属于当前镜头时，关键帧会成为分镜画面。
- 其余关键帧可从素材库手动关联到镜头。

## 保存与预演

- IndexedDB 保存项目、原始文件、缩略图和画面裁切。
- 输入时自动保存。编辑器顶部显示保存状态。
- 撤销和重做覆盖场景、镜头、画幅、裁切和素材关联。
- 素材上传与独立关键帧保留在素材库。
- 撤销记录保留最近 40 步，并随项目恢复。
- 拖动时间轴进度条可定位镜头。
- 图片和视频按镜头时长预演。
- 预演静音。较短视频会停在最后一帧。
